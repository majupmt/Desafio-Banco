# 💰 Projeto Banco em Java

Este é um projeto simples de simulação de um sistema bancário em Java.  
Criado para praticar conceitos como variáveis, estruturas de decisão, laços de repetição e entrada de dados com `Scanner`.
---

## 📋 Funcionalidades

- Visualizar informações da conta
- Consultar saldo
- Transferir valores
- Receber valores
- Encerrar o programa

---

## 🏦 Dados da conta (pré-definidos)

- **Nome:** Gabriel Dias  
- **Tipo de Conta:** Corrente  
- **Saldo Inicial:** R$15.000,00  

---

## 📌 Menu de Opções

```text
** Digite sua opção **
